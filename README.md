# Cybersecurity Portfolio

Public portfolio built for **WQE7001 Cyber Security** at Universiti Malaya.

**Live site:** https://jav-um.github.io/cybersecurity-portfolio/

This repository holds the source of my cybersecurity portfolio: an *About me*, my
technical skills, certifications and training, hands-on projects with evidence, a
reflection on my learning journey, my career objective and professional contact
information.

## Projects
- [Virtual Lab Setup](projects/virtual-lab-setup/) - building an isolated home lab for safe practice.
- [Nmap Service Scan](projects/nmap-service-scan/) - host discovery and service/version enumeration on my own lab.
